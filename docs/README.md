## 文書の更新ルール

1. 仕様変更時は該当文書を**最新実装と同期**させる。
2. 文書間で矛盾が生じた場合は、`02-詳細仕様設計書.md` を基準とする。
3. 各文書冒頭の「改訂履歴」に変更日・変更内容・担当者を追記する。
4. 新規ドキュメント追加時は本インデックスにも追記する。
